# Vibe Coding Skill

面向 **Codex** 的中文技能：逐步明确模糊产品想法，生成可实现、可验收的开发提示词；明确要求开发时，继续完成对应实现和验证。

技能入口：[vibe-coding/SKILL.md](vibe-coding/SKILL.md)。详细用法：[使用指南](docs/使用指南.md)。

## 安装

1. 克隆本仓库，或下载仓库ZIP并解压。
2. 将其中的 **`vibe-coding/` 文件夹整体**复制到 `~/.codex/skills/vibe-coding/`；自定义技能目录以宿主配置为准。
3. 保留`SKILL.md`、`references/`和`agents/`的目录关系，在Codex新对话中显式调用`$vibe-coding`。

技能本身无需额外的Python、Node.js、API密钥或MCP。实际开发项目仍可能需要相应运行环境。

## 调用示例

引导明确想法：

```text
使用 $vibe-coding。我想做个小游戏，但还没想清楚。请一次问一个关键问题，引导我明确需求。
```

只生成提示词：

```text
使用 $vibe-coding。帮我写个人待办网页的开发提示词：支持新增、完成、筛选、本地保存，手机可用。只要提示词，暂不开发。
```

实际开发前，先打开目标项目目录：

```text
使用 $vibe-coding。请在当前项目实现以下需求，沿用现有技术栈，完成后实际验证：
【填写需求】
```

普通独立修Bug、代码评审和具体小改动不单独自动触发；显式调用时按用户要求处理，不强制访谈。

## 工作方式

- 区分用户决定、可查事实与工程细节，保留已确认要求。
- 需求充分时直接交付；只要提示词时，未选接口可列为接入前待核实事项。
- 实际实现缺少必要接口、凭据或业务决定时，核实所缺条件并推进独立部分。
- 参考按需加载，覆盖引导、成文、执行、交接，以及游戏、界面、数据、AI功能和工作流等机制。
